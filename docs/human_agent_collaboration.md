# Human-Agent Collaboration

终审可按“3 名队员 + 自研 AI Agent”组织协作。

## 角色分工

- 任务输入员：确认授权范围，创建任务，上传样例或目标。
- 结果研判员：查看 Step、DecisionTrace、工具证据和风险等级。
- 报告/提交员：导出 Markdown/HTML 报告，整理 SRC 或答辩材料。

## Agent 提升吞吐量的方式

- 自动理解任务输入并推荐场景。
- 自动编排 FileParser、Web、Java、Log 等工具。
- 自动生成报告和修复建议。
- 每一步保存审计链，方便队员复核。
- 工具启停让团队能按授权范围调整能力。

## 安全协作原则

- 人确认授权范围。
- Agent 只执行只读、有限、可审计动作。
- 中高风险动作进入人工确认机制。
- 所有报告保留可复现信息，便于回看和答辩。
