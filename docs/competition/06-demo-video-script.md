# 演示视频录制脚本

建议时长 5-7 分钟。视频应使用脱敏的授权样例，不展示模型 Key、平台 Token、Cookie、Authorization、真实攻击目标、题目答案或隐藏推理。

## 录制前准备

- 在干净环境完成 `npm run check` 和 `npm --prefix frontend run build`。
- 准备一个本地、授权、无敏感数据的 ZIP/二进制样例；不要使用真实恶意样本或比赛题目答案。
- 启动审计台，确认浏览器地址栏只包含本地或已获授权的演示地址。
- 准备一个会被策略拒绝的越界操作，用于展示安全边界；不向任何真实外部主机发包。

## 分镜与讲述

| 时段 | 画面 | 讲述要点 |
| --- | --- | --- |
| 0:00-0:35 | 标题页与仓库首页 | 项目定位：面向授权网络安全任务的自主决策运行时；模型负责判断，系统负责边界。 |
| 0:35-1:10 | 架构图或 `docs/architecture.md` | 展示输入、决策、策略、工具、证据和审计的闭环；强调主动网络能力经过 `PolicyEngine`。 |
| 1:10-2:20 | 控制台创建本地材料分析任务 | 展示 agent 先理解任务、提交计划和假设，不直接执行任意命令。 |
| 2:20-3:20 | 决策轨迹 | 逐条解释“做什么、为什么、影响、结果、下一步”；展示模型、上下文、策略和工具来源筛选。 |
| 3:20-4:10 | ZIP/二进制分析轨迹 | 展示 `extract_archive` 或 `search_artifact` 的受限调用与结果；说明 ZIP 条目、大小、路径和输出上限。 |
| 4:10-4:45 | 逆向/PWN 工具能力文档 | 展示 Radare2、JADX、Pwntools、GDB 等由 allowlist 和 sandbox 管理，不能借此绕过网络策略。 |
| 4:45-5:30 | 策略拒绝与 checkpoint | 展示越权请求被拒绝、失败分类和计划修订；强调 scope 只能收窄。 |
| 5:30-6:10 | 审计、回放与分支 | 展示 `audit.jsonl` 的哈希链、从事件回放/分支的能力；说明不保存隐藏推理或凭据。 |
| 6:10-6:40 | 结尾 | 总结：自主决策、受控执行、证据验证、可审计解释；由人保留授权与最终决策。 |

## 录制验收

1. 画面中无 Key、Token、Cookie、Authorization、真实内部地址或答案。
2. 展示至少一次计划、一次策略判定、一次工具结果和一次 checkpoint/结论。
3. 解释二进制工具链只是受控能力，不代表允许对非授权目标操作。
4. 口播只陈述可由代码、文档或演示轨迹复核的事实，不展示未经验证的成功率。
5. 导出文件命名建议：`烛龙玄枢_XH-202609_演示视频.mp4`，并在提交前检查音画同步和清晰度。
