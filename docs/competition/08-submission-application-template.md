# 报名与邮件提交模板

本模板根据 XH-202609 比赛方案的“作品提交方式”整理。请以主办方的最新通知、报名系统和学校流程为准。

## 1. 系统报名与申报表

```text
申报单位：[待填写]
申报人姓名：[待填写]
团队成员：[待填写]
指导教师：[待填写]
作品名称：烛龙·玄枢——具备自主决策能力的通用网络安全智能体
题目编号：XH-202609
```

待办：

1. 在挑战杯报名系统填写与团队实际信息一致的报名信息。
2. 下载系统生成的报名表。
3. 在指定位置加盖学校或单位公章。
4. 将盖章版扫描件上传报名系统，等待审核通过。
5. 保存审核通过的申报表 PDF，作为正式邮件附件。该 PDF 必须由报名系统流程产生，不在仓库中生成或伪造。

## 3. 邮件模板

收件地址：以主办方最新通知为准。

邮件主题格式：

```text
[申报人所在单位]-[申报人姓名]-[作品名称]-[联系电话]
```

示例仅为格式说明，正式提交时替换全部方括号字段：


## 4. 发送前最终核验

- 申报表所有信息与报名系统严格一致。
- 网盘内含源码、部署手册、核心技术文档、测试证据和声明。
- 压缩包、截图、视频、文档中没有密钥、令牌、Cookie、授权头、真实攻击目标或题目答案。
- 网盘链接、提取码、上传时间截图、联系电话和邮件主题均已核验。
- 已保留本地发送记录和最终 commit SHA。
