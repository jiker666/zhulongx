# Judge demo script

1. Start the core service and create a competition task.
2. Show its isolated workspace and capability health.
3. Add two hypotheses and score distinct actions.
4. Execute a safe attachment-inspection tool through the broker.
5. Show emitted evidence, then verify a candidate with evidence and reproduction metadata.
6. Attempt an out-of-scope or malformed action and show the real denial.
7. Open the legacy CTF task page to demonstrate compatibility and frozen Writeup behavior.

Do not claim a flag is accepted unless it is produced by a real tool run and verified by the configured adapter.
