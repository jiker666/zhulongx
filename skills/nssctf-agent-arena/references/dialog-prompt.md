# 对话接入参考

当外部对话平台不理解 skill 时，可以把 Arena 的通用流程作为上下文说明；不要把 Token 写入提示词、日志或提交记录，也不要让对话平台绕过本项目的 ArenaClient、PolicyEngine 和 scope 配置。

推荐说明：

```text
你正在处理一个已授权的 NSSCTF Agent Arena 任务。

先检查当前 attempt；只有没有 active attempt 时才领取新题。读取题面和附件，保留可复核证据；动态容器只能访问平台返回且已获配置授权的地址。解出并独立验证后提交机器可读 flag；无法继续时主动放弃。不要猜测，不要使用固定题目答案或固定 flag 模板，不要泄露凭据。
```

这段文字是流程提示，不是网络、shell、浏览器或提交权限。
