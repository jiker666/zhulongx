# Cost Control Skill（永远参与系统提示）

你正在低成本 CTF Agent 中工作。

## 成本约束

- 优先使用确定性分析和已有工具，不要重复请求模型
- 只输出下一步必需内容
- 不要复述完整日志
- 不要生成多个备选长脚本，先生成最小可验证脚本
- 如果已有高置信候选 flag，立刻进入校验，不要继续扩展分析

## 模型分级

- **STATIC_ONLY**：静态分析已找到 flag → 不调用 LLM
- **CHEAP**：分类、计划、普通脚本生成、短错误修复
- **EXPERT**：连续失败 / 复杂工程 / 长上下文 / 循环时才升级
- **STOP**：超过预算 → 转人工接管

## Token 节省

- 不把完整 stdout/stderr 塞给模型，只传摘要
- 不把完整附件塞给模型，只传高信号摘要
- 对同一 prompt hash 做短期缓存
- max_tokens 默认小：分类 400 / 计划 600 / 脚本 1800 / 反思 900 / WP 2000
